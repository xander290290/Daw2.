Naturaleza de las etiquetas

La naturaleza de las etiquetas la controlamos con la propiedad display.

display: block;

Una etiqueta de tipo block implica que su ancho coincide con el del padre.

display: inline;

Una etiqueta de tipo inline implica que su ancho y alto se adapta al ancho y alto del contenido.

display: inline-block;

Una etiqueta de tipo inline-block implica que sí hace caso al ancho y alto.

display: none;

Una etiqueta de tipo none implica que no es renderizada.
